# Shadow Text — генератор светильников с тенью-надписью

🌐 **Открыть приложение:** [https://grafsnikers.github.io/ShadowTextGen/](https://grafsnikers.github.io/ShadowTextGen/)

Веб-приложение (работает полностью в браузере, без бекенда): пользователь
вводит текст, приложение строит 3D-модель светильника, которая при подсветке
точечным источником света проецирует **тень в форме этой надписи** на стену.
Модель можно покрутить в 3D-редакторе и скачать в формате **STL** для печати
на 3D-принтере.

## Как это работает

1. Из TTF-шрифта (поддерживается кириллица) извлекаются контуры букв
   (библиотека `opentype.js`), включая внутренние «дырки» букв (О, В, Ю…).
2. Текст размещается в «стеновых» координатах: центр надписи — над лампой,
   низ — на заданной высоте над светильником, размер — ровно заданный.
3. Строится **модель-конус** (усечённая пирамида вдоль лучей): сечения
   параллельны стене, задняя грань крупнее, передняя анаморфически сжата,
   боковые грани лежат точно на лучах «лампа → контур тени». Поэтому тень
   на стене — ТОЧНАЯ копия текста: у плоской модели передняя и задняя
   грани проецировались бы с разным масштабом и края размазались бы.
4. В сцене видно всё в реальном времени: бра на стене светит вверх,
   модель висит над ним, тень — надпись на стене.
5. Готовая геометрия экспортируется в бинарный STL (1 единица = 1 мм),
   уже развёрнутая для печати задней (большой) гранью на стол.

## Запуск

Приложение — статические файлы, но ES-модули требуют HTTP-сервера
(при открытии `index.html` двойным кликом браузер заблокирует модули):

```bash
# любой из вариантов:
npx serve .          # Node.js
python -m http.server  # Python
```

Затем откройте `http://localhost:8000` (или порт, который покажет `serve`).

Интернет нужен при загрузке страницы: Three.js, opentype.js и шрифты
подгружаются с CDN (jsDelivr).

## Управление

- **Вращение** — левая кнопка мыши, **масштаб** — колесо, **панорама** — ПКМ.
- **Текст** — надпись, которая станет тенью.
- **Шрифт** — PT Sans / Roboto / Montserrat / Pacifico (все с кириллицей).
- **Высота букв на стене, толщина, интервал** — параметры тени и модели (мм).
- **Нижняя планка / рамка** — соединительные элементы для печати одной деталью
  (планка видна в тени как полоса под текстом).
- **Светильник ↔ стена** — вынос бра от стены (не больше 10 см).
- **Модель ↔ стена** — чем ближе модель к стене, тем она крупнее и тем
  меньше полутень от реальной (не точечной) лампы.
- **Низ тени над светильником** — на какой высоте над лампой появится низ
  надписи-тени (например, 200 мм ≈ 20 см).
- Тень **точно без искажений**: модель — конус вдоль лучей света, каждая
  боковая грань лежит на луче, поэтому каждый луч проходит через тело
  ровно один раз. Проверено численно: проекции передней и задней граней
  совпадают до сотых миллиметра.
- **Скачать STL** — экспорт модели для слайсера.

## Печать

- Печатайте модель **задней (большой) гранью на стол** — STL уже
  экспортируется в этой ориентации, поддержки не нужны.
- В слайсере (Cura, PrusaSlicer, Bambu Studio) просто откройте STL,
   масштаб по умолчанию уже в миллиметрах.
- Тень от идеальной точечной лампы — точная. Реальная лампа имеет размер:
  полутень ≈ `r·d/(L−d)` (r — радиус колбы, d — модель↔стена, L — лампа↔стена).
  Для чётких краёв берите маленькую лампу и ставьте модель ближе к стене
  (следите за оценкой полутени в панели).

## Структура проекта

```text
index.html        — разметка + importmap (CDN Three.js)
css/style.css     — стили интерфейса
js/main.js        — сцена, UI, экспорт STL
js/fonts.js       — загрузка TTF и построение контуров букв
js/model.js       — сборка единой геометрии модели (буквы + планки)
```

## Технологии

- [Three.js](https://threejs.org) (r160) — 3D-сцена, тени, экспорт STL
- [opentype.js](https://opentype.js.org) — парсинг TTF-шрифтов
- Шрифты — из открытого репозитория [google/fonts](https://github.com/google/fonts)
